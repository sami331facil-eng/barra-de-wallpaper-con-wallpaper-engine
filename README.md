# barra-de-wallpaper-con-wallpaper-engine
Barra flotante de selección de wallpapers para Windows, inspirada en la estética minimalista de Hyprland. Miniaturas transparentes, selección mediante teclado y diseño moderno para personalizar tu escritorio.


WallpaperQuickSwitch — Hyprland Style

Una barra flotante para cambiar fondos de pantalla en Windows, inspirada en la estética minimalista de Hyprland y los escritorios Linux personalizados.

El proyecto busca ofrecer una experiencia visual limpia, con una galería horizontal de wallpapers, transparencias y navegación mediante teclado, sin buscadores ni paneles innecesarios.

✨ Características

- 🖼️ Galería horizontal: muestra miniaturas de tus wallpapers en una barra compacta.
- 🎨 Estética Hyprland: diseño minimalista con detalles modernos y una selección visual destacada.
- 🌫️ Interfaz transparente: elimina el fondo opaco para integrarse mejor con el escritorio.
- ⌨️ Control por teclado: navega entre los fondos sin depender del ratón.
- ⚡ Acceso rápido: abre y cierra la barra mediante un atajo de teclado.
- 🧹 Interfaz limpia: sin buscador ni elementos visuales innecesarios.

🎮 Controles

Tecla| Acción
"←"| Seleccionar wallpaper anterior
"→"| Seleccionar wallpaper siguiente
"Enter"| Aplicar el wallpaper seleccionado
"Esc"| Cerrar la barra

Los controles y el atajo de apertura pueden variar según la versión del script.

🛠️ Requisitos

- Windows 10 u 11.
- "AutoHotkey v2" (https://www.autohotkey.com/).
- Wallpaper Engine, si utilizas la integración con ese programa.
- Una colección de wallpapers compatible con la versión instalada.

🚀 Instalación

1. Descarga o clona este repositorio.
2. Instala AutoHotkey v2.
3. Configura la ruta de tus wallpapers si el script lo solicita.
4. Ejecuta el archivo ".ahk".
5. Utiliza el atajo configurado para abrir la barra.

🎯 Objetivo

Crear una experiencia similar a los selectores de fondos de los escritorios Linux personalizados, adaptada a Windows y con especial atención a la estética, la transparencia y la comodidad de uso.

📌 Estado del proyecto

Proyecto personal en desarrollo. Algunas funciones pueden requerir ajustes según la configuración de Windows y la instalación de Wallpaper Engine.
